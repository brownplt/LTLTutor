Until Review

You may think that if {{ ltl_code('x') }} is always true, the formula {{ ltl_code('x U y') }} ("x until y") is always satisfied, even if {{ ltl_code('y') }} is never true.

In reality, {{ ltl_code('x U y') }} states two things:

  • {{ ltl_code('x') }} holds at every moment in time until {{ ltl_code('y') }} becomes true. This means the {{ ltl_code('x') }} must be true at the current state.
  • {{ ltl_code('y') }} will eventually become true at some point in the future.
What this means is that if {{ ltl_code('y') }} never becomes true, then {{ ltl_code('x U y') }} is false, regardless of whether {{ ltl_code('x') }} holds for all preceding moments.
