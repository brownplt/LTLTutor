Until Refutation

You might think that {{ ltl_code('x U y') }} (Until) is satisfied only when both the right subterm {{ ltl_code('y') }} and the negation of the left subterm {{ ltl_code('x') }} hold true. However, the "Until" operator is more permissive than this. In fact, it only requires that {{ ltl_code('x') }} holds true at every step until {{ ltl_code('y') }} becomes true. Once {{ ltl_code('y') }} holds, it doesn't matter whether {{ ltl_code('x') }} is true or false.
To put it another way: {{ ltl_code('y') }} eventually becomes true at some point in the future, and until that moment, {{ ltl_code('x') }} must continuously hold true. This does not require {{ ltl_code('x') }} to stop being true at the same time that {{ ltl_code('y') }} becomes true.
